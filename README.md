## Описание проекта

Данный проект представляет собой расчётно-графическую работу
по дисциплине **«Машинное обучение и большие данные»**.

Разработан интерактивный веб-дашборд на основе библиотеки
**Streamlit** для инференса (вывода) моделей машинного обучения
и анализа данных о ценах на подержанные автомобили
молдавского рынка.

---

## Задача

**Тип задачи:** Регрессия

**Целевая переменная:** Цена автомобиля в евро `Price(euro)`

**Метрика качества:** Коэффициент детерминации R²

---

## Датасет

| Параметр | Значение |
|----------|----------|
| Источник | Рынок подержанных авто Молдовы |
| Строк | ~37 000 |
| Целевая переменная | Price(euro) |

### Исходные признаки:

| Признак | Описание | Тип |
|---------|----------|-----|
| Make | Марка автомобиля | Категориальный |
| Model | Модель автомобиля | Категориальный |
| Year | Год выпуска | Числовой |
| Distance | Пробег (км) | Числовой |
| Engine_capacity(cm3) | Объём двигателя | Числовой |
| Style | Тип кузова | Категориальный |
| Fuel_type | Тип топлива | Категориальный |
| Transmission | Коробка передач | Категориальный |

## Модели машинного обучения

| # | Модель | Тип | R² |
|---|--------|-----|----|
| ML1 | Ridge Regression | Классическая | ~0.82 |
| ML2 | Gradient Boosting | Бустинг | ~0.84 |
| ML3 | CatBoost | Продвинутый бустинг | ~0.85 |
| ML4 | Random Forest | Бэггинг | ~0.83 |
| ML5 | Stacking | Стэкинг | ~0.84 |
| ML6 | Neural Network | Нейросеть | ~0.84 |

Гиперпараметры всех моделей подобраны автоматически с использованием библиотеки **Optuna**

---

## Предобработка данных

### Очистка:
- Удаление аномальных значений (выбросов) по диапазонам
- Заполнение пропусков медианой и модой по группам

### Кодирование:
- **One-Hot Encoding** — Style, Fuel_type, Transmission
- **Frequency Encoding** — Make, Model

### Feature Engineering:
- Vehicle_age — возраст автомобиля
- Log_Distance — логарифм пробега
- Log_Engine — логарифм объёма двигателя
- Age_x_Distance — возраст × пробег
- Distance_per_engine — пробег / объём двигателя
- и другие производные признаки

## Структура веб-приложения
Дашборд состоит из главной и 4 страниц с информацией:

Страница 1 — Разработчик: ФИО, группа, фото, описание работы

Страница 2 — Датасет: Исходные данные, предобработка, кодирование

Страница 3 — Визуализации: 6 типов графиков (гистограмма, heatmap,
boxplot, scatter, violin, line)

Страница 4 — Прогнозирование
- Ручной ввод данных
- Загрузка CSV файла
- Вывод результата в EUR
